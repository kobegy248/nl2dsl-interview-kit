# 高压追问详细答案补充设计

## 目标

在现有《高宇-NL2DSL简历面试参考答案.md》末尾新增一章详细回答模板，对应追问清单中新增的高压风险点。答案要体现真实落地经验的表达方式：职责边界清楚、链路细节具体、指标口径谨慎、生产和开源不混淆。

## 范围

本次只追加答案模板，不重写原有参考答案。新增内容围绕 8 个风险点展开：

- 项目真实性与边界
- Vibe Coding 掌握度
- 性能指标可信度
- RAG 与向量库选型
- 大数据与 Spark 真实性
- 代码现场讲解
- 生产落地边界
- Java 后端基本盘

## 内容结构

新增章节标题为“十一、高压追问详细回答模板”。每个风险点包含：

1. 总回答口径：先给面试时可以开口说的总体表达。
2. 详细回答模板：选 2 到 3 个最容易被问穿的问题写成可口述答案。
3. 不要这么说：提醒避免夸大、混淆或虚构。

## 写作原则

- 答案要像真实工程师复盘项目，不像营销稿。
- 多写输入输出、模块边界、失败处理、评测口径、取舍原因。
- 不编造不可证明的生产规模、用户量、准确率或成本数据。
- 对公司项目、开源项目、个人抽象复现保持清晰边界。
- 可以用“我会这样解释”“我一般会先说清楚”这类口述风格，方便面试前直接阅读。

## 验收标准

- 新增章节覆盖 8 个风险点。
- 每个风险点至少包含 2 个详细回答模板。
- 每组都有“不要这么说”。
- 不新增与简历和现有文档冲突的事实。
- 文档只追加新章节，不改写原有答案主体。
